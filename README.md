# JuniorSoftwareEngineer-IMRAI-

1. Analyze a financial dataset (pick any) to derive statistical insights and visualize trends.

   
File name: analyzing financial dataset.py

I choosed Apple stock data.

This provides an interactive stock analysis tool for Apple Inc. (AAPL) using Python, Yahoo Finance API, and Data Visualization. It helps in understanding stock price trends, computing returns, and analyzing stock behavior using moving averages, histograms, and correlation heatmaps.

 Technologies used:
- Python – Core programming language for data analysis
- Yahoo Finance API (yfinance) – Fetches stock data
- Pandas – Data manipulation and analysis
- Matplotlib & Seaborn – Data visualization
- NumPy – Numerical operations
